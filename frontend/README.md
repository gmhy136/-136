# frontend · 云记录

云记录前端：Next.js 16（App Router / Turbopack）+ React 19 + TypeScript + Tailwind CSS 4 + TanStack Query 5 + Zustand 5。

## 快速开始

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # 生产构建（含 TypeScript 类型检查）
```

`NEXT_PUBLIC_API_BASE` 默认 `http://localhost:8080/api/v1`，可在 `.env.local` 覆盖。

完整说明见仓库根目录 [README](../README.md)。
